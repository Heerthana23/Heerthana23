## 🚀 Featured Projects

### 🤖 Fraud Detection System — Machine Learning Dashboard

A machine learning-based fraud detection application developed to identify potentially fraudulent financial transactions.

- Developed a fraud detection model using **XGBoost**.
- Worked with the PaySim financial transaction dataset.
- Performed data filtering and preprocessing for model development.
- Built an interactive dashboard using **Streamlit**.
- Integrated the trained machine learning model (`xgb.pkl`) into the application.
- Focused on identifying suspicious transactions and presenting prediction results through an interactive interface.

**Dataset Overview:**
- Processed transactions: 39,315
- Fraudulent transactions: 116
- Fraud percentage: 0.2951%

**Technologies:** Python, XGBoost, Streamlit, Pandas, Machine Learning

🚀 **[View Live Application](https://fraud-detection-system-dy2nznszmbpkrethvfjm4r.streamlit.app/)**
